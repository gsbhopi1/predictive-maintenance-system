# Predictive Maintenance System

An end-to-end machine learning project for identifying
industrial machine failure risk using operational data.

## Objectives

- Analyze machine operational data.
- Identify patterns associated with machine failures.
- Develop and evaluate machine learning models.
- Explain model predictions.
- Build an interactive failure risk monitoring application.

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
